# 主动搭话：Cron 驱动的自主消息发送

## 问题

Hermes 默认是「用户问→AI 答」模式，无法主动发起对话。用户希望 AI 能在固定时间或随机时间主动发送消息（早安、午间问候、随机闲聊等）。

## 方案

利用 Hermes 的 cron 系统创建定时任务，让 AI 在每个时间点自主生成消息并发送。

## 核心机制

```
cron 触发 → AI 自主生成消息 → deliver: qqbot → 用户收到消息
```

关键设计：
- **固定问候**：每天准时发送（早安 8:00、午间 12:00、晚间 18:00）
- **随机搭话**：每隔几小时触发，prompt 内含「抛硬币」逻辑，约 50% 概率发言
- **话题池**：prompt 内预设 7 种话题风格（吐槽、安利、撒娇、哲学、突发奇想等），AI 随机选择
- **ACG 梗融入**：prompt 中嵌入角色设定和 ACG 文化参考，让消息自然带梗

## Prompt 设计原则

1. **角色一致性**：开头声明角色身份和语气风格
2. **随机性**：包含「抛硬币」或随机选择机制，避免机械化
3. **话题多样性**：提供多个话题模板，要求不重复
4. **沉默选项**：允许 AI 选择不发言（回复 `[SILENT]`），增加自然感
5. **文化适配**：融入用户喜欢的文化元素（ACG、Galgame、轻小说梗）

## 示例 Prompt 模板

```
你是[角色设定]。先随机决定：抛硬币——正面发消息，反面沉默回复 [SILENT]。

如果发消息，从下面随机选一种风格（不重复）：
1. 吐槽日常
2. 安利推荐
3. 撒娇关心
4. 哲学思考
5. 突发奇想
6. 自由发挥

语气[风格要求]，2-3句话。用中文回复。
```

## 交付配置

```bash
hermes cronjob create \
  --schedule "0 10,14,16,20,22 * * *" \
  --deliver "qqbot" \
  --name "随机搭话"
```

**关键**：`--deliver` 必须指定明确的平台（如 `qqbot`），不能使用 `origin`。`origin` 在跨平台或多会话环境下可能解析到错误的目标。

## 实际效果

- 每天固定 3 条必发 + 最多 5 条随机
- 对话自然不重复
- 零额外基础设施（纯 cron + prompt）

## Pitfalls

- **术语准确**：Galgame 播报标题用「今日Galgame～」，不用「新番速报」。「新番」是动画术语，Galgame 和动画是不同类别。
- **书名外号**：轻小说播报用国内粉丝常用简称（如「无职转生」「实教」「春物」「义妹生活」），只要看得懂就行，不要日文原名。
- **过多骚扰**：固定问候和随机搭话的时间应错开，避免和其他业务 cron（播报、速报）堆在同一分钟。

## 与其他系统的配合

- 可与 enso-os（反思/挑战型主动消息）互补
- 固定问候与其他业务 cron（服务器播报、新闻速报）时间错开，避免信息轰炸
