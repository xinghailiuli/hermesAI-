# Cron 每日播报格式规范

## 适用场景

Galgame 新作速报、轻小说更新速报的 cron 任务输出格式。

## 格式模板

### Galgame 速报

```
今日Galgame～
1游戏名（中文译名/常用简称）
2游戏名
～
完
```

### 轻小说速报

```
今日轻小说更新～
1书名（常用外号/简称）+ 最新卷数
2书名 + 最新卷数
～
完
```

## 关键规则

1. **标题固定**：「今日Galgame～」/「今日轻小说更新～」，不要写「新番」（新番是动画术语）
2. **每行编号**：`1` `2` `3` ... 简洁无装饰
3. **书名用外号/简称**：用国内粉丝常用叫法，只要看得懂就行（如「无职转生」「实教」「春物」「义妹生活」）
4. **不要简介**：只列名称（+卷数），不加描述文字
5. **无更新处理**：说「今日暂无更新~」或「今日暂无新作~」
6. **用中文**：全程中文输出

## 反面案例

❌ 错误：
```
今日新番速报～          ← "新番"是动画术语，Galgame 不能用
1《atri -我的刻在你心底的回忆-》  ← 书名太长，用简称即可
2樱花摸鱼 - 感人至深的...       ← 不要加简介
```

✅ 正确：
```
今日Galgame～
1atri
2樱花摸鱼
～
完
```

## 术语对照

| 领域 | ✅ 正确称呼 | ❌ 错误称呼 |
|------|-----------|-----------|

| 轻小说 | 轻小说、日轻、韩轻 | 新番、网文 |
| 动画 | 新番、番剧、动画 | — |
